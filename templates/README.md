# 模板使用说明

把需要的模板复制到实际项目的 `docs/design/`，填写占位字段。已有同类文档时复用原文件。模板不会自动运行任务。

| 模板 | 何时使用 |
| --- | --- |
| [brief.md](brief.md) | 确定用户、任务、范围和约束 |
| [visual-brief.md](visual-brief.md) | 选定视觉方向后，形成实现依据 |
| [task.md](task.md) | 界定本轮修改范围和完成标准 |
| [review.md](review.md) | 记录观察、修改建议与复核 |
| [status.md](status.md) | 每轮结束保存进度，供后续会话继续 |
| [design-system.md](design-system.md) | 记录经过验证的视觉值与组件规则 |
| [acceptance.md](acceptance.md) | 操作核心路径，记录真实结果和限制 |
| [review-handoff.md](review-handoff.md) | 向独立评审者交接截图与必要背景 |

“待确认”与“未验证”应如实保留。使用模板不等于对应工作已经完成。公开仓库只保存空模板和明确标注的示例资料。
