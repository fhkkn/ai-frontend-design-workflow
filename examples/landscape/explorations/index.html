THREE WAYS OF SEEING

同一片山水，
三种观看方式。

先看画面，再选方向。
三份独立页面，共用一组风景摄影。
区别在于怎样进入、停留，以及发现下一幅。

A / IMMERSION影像占满视野
进入长卷 ↗

沉浸长卷

山水铺满屏幕，巨幅字与细小索引形成对照。沿章节切换，或隐去文字，只看风景。

观看感强；查找效率让位于停留。

体验 A ↗
B / STILLNESS留白构成画面
步入画廊 ↗

留白画廊

竖排题签、错落画幅与大片空白。像翻阅一本画册，展开一幅，再细看其中的山水。

节奏疏朗；黑白处理弱化自然色彩。

体验 B ↗
C / DISCOVERY由索引探索风景
展开图志 ↗

山川图志

暗色底图、等高线与醒目的荧光索引。由湖面到山脊再到夜色，切换观察对象。

探索感强；图形信息比纯观景更活跃。

体验 C ↗
本轮可体验

A 切换景色 / 纯观景；B 展开画幅 / 切换黑白与原色；C 切换索引 / 隐藏等高线 / 放大影像。缩览用于比较，进入页面后可操作。

摄影与图形为视觉探索素材；没有音频、真实地图定位或旅行服务。定稿采用沉浸长卷，候选保留供比较。
