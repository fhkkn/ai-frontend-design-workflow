# 实际设计规范

范围：根目录定稿；探索页的不同结构保留自己的样式。

| 项目 | 实际规则 |
| --- | --- |
| 文字与底色 | 主文字 `#f3f3e7`，辅助 `#e0e7df`，背景 `#102b31` |
| 标题 | STSong / SimSun / serif；桌面流动 88–148px，超宽最高166px；窄屏74–108px；两行，第二行右移 |
| 辅助排版 | 系统无衬线；编号 Consolas / monospace；章节用线和文字共同表示选中 |
| 页面结构 | 头部、中间伸展构图、底部章节；700px 以下中部单列并移除前后图标按钮，保留章节 |
| 图片 | 两图层交叉淡化；每景独立 desktop/mobile object-position；保留有意义的替代文本 |
| 动效 | 720ms；用户主动切换，无自动轮播；减少动态偏好关闭过渡 |
| 控件 | 主要按钮最小44px高；原生 button、aria-pressed、可见焦点轮廓 |
| 纯观景 | 隐藏区设置 inert 和 aria-hidden，收起遮罩；返回按钮保留，Escape 可退出 |
| 状态 | 解码成功后更新题签与地址；失败保留当前景色并提供重试；连续请求仅应用最后一次 |
| 地址 | `#lake`、`#ridge`、`#night`，刷新定位；不写入浏览器存储 |

未完成所有摄影位置的文字对比度测量或完整 WCAG 审核。规范记录实现，不替代验收结果。
