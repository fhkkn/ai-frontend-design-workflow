# 本案例设计规范

视觉方向：文档工作台。阅读正文优先，索引用于切换，绿色用于品牌和主操作。

| 项目 | 实际规则 |
| --- | --- |
| 页面背景 | `#f0f0e9` |
| 文档底色 | `#fcfbf7` |
| 正文 | `#222b26` |
| 次级文字 | `#66716a` |
| 品牌与主操作 | `#335b48`，按钮白字 |
| 分隔线 | `#dedfd5`，不承担唯一的状态提示 |
| 字体 | 系统字体栈；正文 15px、2 倍行高；标题桌面 32px，手机 26px |
| 桌面结构 | 容器上限 1180px；索引 270px；正文使用可收缩的剩余空间 |
| 中间宽度 | 900px 以下减少左右留白，索引 230px |
| 手机结构 | 640px 以下上下排列；列表区域可水平滚动，正文按页面纵向滚动 |
| 主要操作 | 手机保存按钮占满内容宽度；最小高度 48px |
| 焦点 | 深绿色 2px 外轮廓，外偏移 4px |
| 反馈 | 使用明确文字表示未保存、成功、失败；状态区启用 polite 实时播报 |
| 素材与动效 | 无外部图片、字体、视频或动画；截图来自本地运行页面 |

正文输入框随内容和视口变化调整高度，减少嵌套滚动。标题使用单行原生输入框，长标题可在输入框内移动光标查看；列表标题允许换行。

这份规范只适用于案例。不要把它的颜色、断点、布局或字体尺寸作为所有产品的默认答案。
